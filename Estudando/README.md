## 🎯 Sobre o Projeto

Bem-vindo ao meu repositório de estudos em Java! Este espaço é dedicado a registrar minha jornada de aprendizado e aprofundamento na linguagem, com um foco especial nos conceitos e paradigmas da **Programação Orientada a Objetos (POO)**.

O objetivo é criar um portfólio prático com exercícios que vão desde a sintaxe básica até a implementação de sistemas mais complexos utilizando os pilares da POO.

## 📁 Estrutura do Repositório

O projeto está organizado dentro da pasta `src` (source), separando os exercícios básicos dos exemplos de Programação Orientada a Objetos para maior clareza.

```

/Java
└── src/
├── 📁 Exercicios/
|   └── (Programas para lógica e sintaxe)
|
└── 📁 POO/
└── (Classes, objetos e exemplos de OOP)

````

## 📚 Tópicos Abordados

Os códigos neste repositório exploram diversos conceitos fundamentais da linguagem Java e da POO, incluindo:

* **Sintaxe Básica:** Variáveis, tipos de dados, operadores e estruturas de controle (`if`, `for`, `while`).
* **Classes e Objetos:** A base da POO, com a criação de moldes (classes) e suas instâncias (objetos).
* **Encapsulamento:** Proteção dos dados com modificadores de acesso (`private`, `public`) e uso de métodos `getters` e `setters`.
* **Herança:** Reutilização de código através da criação de superclasses e subclasses.
* **Polimorfismo:** A capacidade de um objeto assumir diferentes formas, geralmente através da sobrescrita de métodos.
* **Abstração:** Foco nos aspectos essenciais de um objeto, escondendo detalhes de implementação com classes abstratas e interfaces.

## ⚙️ Como Compilar e Executar

Os arquivos foram escritos em Java e podem ser compilados e executados via terminal usando o JDK (Java Development Kit).

**1. Navegue até o diretório `src`:**
```bash
# Estando na raiz do projeto 'Java'
cd src
````

**2. Compile o arquivo `.java`:**
*Use o caminho completo do arquivo a partir de `src`.*

```bash
# Exemplo para um arquivo dentro da pasta POO
javac POO/NomeDaClasse.java
```

**3. Execute o programa compilado:**
*Informe o caminho completo da classe (com `.` em vez de `/`).*

```bash
# Exemplo de execução
java POO.NomeDaClasse
```
